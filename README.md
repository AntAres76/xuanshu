# 玄枢 · 八字紫微奇门排盘

纯前端、可离线使用的排盘工具：直接用浏览器打开 `index.html` 即可（也可部署到 GitHub Pages 等任何静态空间）。全部计算在本机完成，不上传数据。

## 这一版新增

- **原理释义**：盘面上带虚线的字和“?”按钮都能点开，右侧抽屉会说明它是怎么算出来的、为什么这样定、古籍怎么说、在这张盘上牵动了什么。条目之间可以继续点、可以返回。
- **命例联动**：排过的盘自动存成命例（相同的人只存一份）。顶部“当前命例”一切换，八字、紫微、奇门年命、择日生肖一起同步；合婚可以直接从命例里选人。
- **紫微斗数**：完整十二宫盘，三方四正高亮，生年四化、宫干飞化，大限、小限、流年、流月及运限四化，格局识别，逐步排盘过程。
- **合婚**：每项分数可展开看原因，并新增分数算式、四柱交叉表、夫妻宫与配偶星、命卦对照。
- **手机 / iPad**：可添加到主屏幕，全屏、离线使用。

## 功能

**八字排盘**
- 公历 / 农历（含闰月）输入，出生地城市库自动填经度，真太阳时（经度差 + 均时差）、中国 1986–1991 夏令时自动提示
- 子时换日两种规则（23:00 / 0:00），起运两种算法（天数时辰 / 分钟精算）
- 四柱：主星十神、天干地支、藏干及其十神、星运（十二长生）、自坐、空亡、纳音、神煞（四十余种）
- 胎元、胎息、命宫、身宫，生肖星座，出生节气（某节后几天几时）、人元司令、物候
- 干支关系：天干五合、相冲；地支六合、三合、半合、拱合、三会、六冲、相刑、三刑、自刑、相害、相破、暗合
- 五行力量（含藏干、月令旺相休囚死加权）、个数统计、十神力量、缺失五行
- 日主旺衰（得令/得地/得势）、月令格局、喜用忌神（扶抑 + 调候）、开运参考（颜色、方位、数字）
- 大运（起运时间、交运年份）、小运、流年（太岁：值/冲/刑/害/破/合，岁煞）、流月（以节换月）、流日；点选后加入命盘并分析与原局的关系
- 神煞、十神释义；保存档案、分享链接、打印 / 导出 PDF

**紫微斗数（三合派通行安星，底本《紫微斗数全书》）**
- 十四主星、六吉、六煞、禄存天马、杂曜、长生/博士/岁前/将前四组十二神，亮度
- 五行局、命主身主、身宫、生年四化、宫干飞化、来因宫
- 大限、小限、流年、流月（斗君），运限四化叠加到盘上
- 约 60 种格局：只检查成格条件，不判断破格
- 流派选项：闰月处理、晚子时、大限起宫

**奇门遁甲（时家转盘）**
- 拆补法 / 置闰法（超神、接气、芒种大雪置闰）定局，阴阳遁、三元、局数、旬首、值符、值使
- 地盘、天盘（含天禽寄坤）、九星、八门、八神、暗干，中五寄坤二
- 时空亡、驿马，日干 / 时干 / 月干 / 年干 / 年命落宫
- 九星、八门旺衰，门宫、星宫生克
- 格局：伏吟、反吟、六仪击刑、三奇 / 十干入墓、门迫、十干克应（81 组）、三奇得使、九遁、玉女守门、五不遇时、时干入墓等
- 用神速查（求财、事业、考试、婚姻、疾病、官司、出行等自动标出所在宫），前后时辰切换

**其他**
- 黄历：月历（农历、节气、节日）、宜忌、值神黄黑道、建除、冲煞、二十八宿、九星、胎神、彭祖百忌、喜财福贵神方位、吉神凶煞、十二时辰吉凶宜忌
- 择日：在指定范围内查找宜做某事的日子，可筛选黄道日、避开冲自己生肖
- 八字合婚：生肖、年命纳音、日柱（夫妻宫）、五行喜忌互补、配偶星综合评分
- 四柱反查：由四柱反推公历出生时间
- 命例档案：本地保存、搜索、备注、导入导出 JSON
- 深色 / 浅色主题，手机与电脑自适应

## 在 iPhone / iPad 上使用

iOS 的离线缓存只在 HTTPS 网址下开放，所以需要先把这个文件夹放到任意一个 HTTPS 静态空间（如 GitHub Pages）：

1. 用 Safari 打开网址（第一次需要联网）。
2. 分享（新版 iOS 可能要先点地址栏旁的“···”）→ 添加到主屏幕。
3. 从主屏幕图标打开，等提示“已缓存到本机”，之后断网可用。

软件里页脚的“手机 / iPad 安装与离线说明”写了详细步骤。命例只存在本机；删除主屏幕图标会同时删除命例，请先在“命例档案”里导出备份。

电脑上直接双击 `index.html` 也能离线使用。

## 说明

- 历法（节气、农历、干支、起运、黄历）基于 [lunar-javascript](https://github.com/6tail/lunar-javascript)（MIT 许可，见 `js/lib/LICENSE-lunar-javascript.txt`）。
- 旺衰、喜用为通用算法估算；合婚分值是本软件设计的权重，古书没有打分。古籍引文据维基文库本核对，均可从释义页点开原文。紫微逐宫解读是白话归纳，不是原文。紫微安星规则曾与开源库 iztro 的公开算法和测试用例比对。
- 各流派对神煞、暗干、置闰阈值等有不同取法，本工具采用常见取法。命理内容为传统文化参考。
